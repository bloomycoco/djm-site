# Département de la Justice — site statique

Reconstruction du Google Site en site statique (HTML/CSS pur, aucune dépendance).

## Contenu
- `index.html` — Accueil
- `membres.html` — Membres
- `reglement.html` — Règlement
- `style.css` — style partagé

## Publier sur GitHub Pages

1. Crée un nouveau dépôt GitHub (public), par exemple `djm-site`.
2. Mets ces 4 fichiers à la racine du dépôt (pas dans un sous-dossier).
3. Sur GitHub : **Settings** → **Pages** → sous "Build and deployment", choisis **Deploy from a branch**, branche `main`, dossier `/ (root)** → **Save**.
4. Le site sera en ligne quelques minutes après à l'adresse `https://<ton-pseudo-github>.github.io/djm-site/`.

## Remarque sur le contenu

Le texte a été reconstruit à partir d'un résumé du Google Site original (pas une copie caractère pour caractère) — relis notamment les noms/postes de la page Membres et les articles du Règlement pour vérifier qu'ils correspondent exactement à l'original avant publication.
